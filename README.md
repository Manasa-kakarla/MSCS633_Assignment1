# Biox QR Code Generator

A simple Python application for generating QR codes, built for internal or public use by **Biox Systems**. This tool allows you to quickly generate QR codes from URLs, text, or any string-based data and save them as PNG images.

## 🚀 Features

- Generate QR codes for URLs, text, or any data
  
- Save the QR code as an image (`.png`)
  
- Error correction support
  
- Clean and customizable output
  
- Easy to extend with batch or GUI features

## 📦 Requirements

- Python 3.7 or higher
  
- [`qrcode` with `Pillow`](https://pypi.org/project/qrcode/)
